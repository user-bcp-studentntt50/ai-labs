# HU-01 — Verificar autorización de tareas por identidad

## Origen
- **H-WEB-02 (web)** — matriz: `HALLAZGOS.md:59`.
- Evidencia del hallazgo: `web/src/app/dashboard/dashboard.component.ts:45-53`; `web/src/app/tasks.service.ts:11-18`; prueba simulada: `web/src/app/services.spec.ts:59-70`.

## Contexto
- La consulta de tareas envía un `owner` tomado del usuario guardado en el navegador y la solicitud incluye el token de sesión.
- La query se codifica, pero la prueba existente usa una solicitud simulada; no confirma que el servicio vincule `owner` con la identidad autenticada.
- El hallazgo indica que se excluyeron cambios de backend y se eligió documentar solamente. Por tanto, la autorización permanece sin verificar.

## Ajustes necesarios
- Mantener documentado que la prueba web simulada valida la solicitud del cliente, no la autorización del servicio.
- No declarar corregida ni verificada la autorización basándose solo en pruebas web.
- Para verificar el acceso entre identidades se requiere acordar la ampliación de alcance al servicio/backend; ese cambio no está autorizado por el hallazgo actual.

## Criterios de aceptación
- Una prueba web automatizada verifica que la consulta conserva el `owner` enviado por el cliente y la cabecera de autorización; el resultado solo se considera evidencia del request del frontend.
- Una prueba funcional contra el servicio real verifica que una identidad no obtiene tareas de un `owner` distinto. **Pendiente de aprobación de alcance backend**; no se considera cumplido mientras esa verificación no pueda ejecutarse.
- La evidencia de pruebas identifica explícitamente cuáles son simuladas y no presenta una prueba simulada como verificación de autorización del servicio.

## Evidencia esperada
- Resultado de la prueba web de solicitud simulada, referenciada en `web/src/app/services.spec.ts:59-70`.
- Si se aprueba ampliar el alcance: resultado de prueba funcional contra el servicio que verifique el acceso para identidades coincidentes y distintas.
- Registro de que la autorización sigue pendiente hasta contar con esa prueba; no incluir tokens, secretos ni credenciales.
